# بصيرة V4 — موقع الفقه والحديث والشبهات وطلب العلم

## الملفات والنشر
هذه النسخة من ZIP مصممة لرفع الملفات **مباشرة إلى جذر مستودع `Muslim`**. لا يوجد مجلد موقع محيط ولا `data/`. افتح ZIP وارفع `index.html`, `app.js`, `styles.css`, `config.js` وكل ملفات `.json` وبقية الملفات مرة واحدة إلى GitHub Pages.

**الرابط المستهدف:** https://islamtanjawi.github.io/Muslim/

## الأقسام الفعلية
- **24 بابًا و253 موضوعًا**: 137 مدخلًا توضيحيًا ذا مراجع، و116 عنوانًا لا تملك حاليًا توثيقًا تفصيليًا؛ هذه العناوين لا تُسوّق بوصفها فتاوى.
- **الأحاديث:** 21 حديثًا مختارًا من البخاري ومسلم مع رقم الرواية ومقتطف وشروح موجزة وروابط المتن الأصلي على Sunnah.com؛ لا تنسب للموقع صفة تحقيق علمي خاص به.
- **الرد على الشبهات:** 12 مادة سؤال/جواب موثقة بمراجع وروابط قرآن وحديث؛ تشمل ادعاء تحديد وقت يوم القيامة.
- **طلب العلم:** 4 مسارات، 20 درسًا وروابط أدلة، مع حفظ التقدم في localStorage على الجهاز الحالي.
- **المرئيات:** رابطان قدّمهما صاحب الموقع، أحدهما للشيخ مصطفى العدوي والآخر لهيثم طلعت؛ لم نُفرّغ التسجيل أو نعتمده كدليل منقول.
- الموسوعة، البحث، المفضلة، الصفحات القانونية، وضع الهاتف/الكمبيوتر والظلام، المساعد المحلي وروابط المراجع.

## مبدأ التوثيق
المصدر المرفق دليل على **النص المحدد الذي يدعمه**، وليس ضمانًا لجميع تفاصيل الفتوى. تُفصل الآيات والأحاديث الصحيحة وأقوال العلماء وقرارات المجامع الفقهية. ما يزال المحتوى بحاجة إلى **مراجعة عالم أو فريق تحرير شرعي مؤهل** قبل ادعاء اعتماد كل فتوى. لا ينبغي استبدال عبارة التحفظ بتأكيد الصحة لمجرد وجود رابط إلى مصدر.

## الدردشة وCloudflare (اختياري في هذه المرحلة)
تعمل الدردشة المحلية دون أي مفتاح. لإضافة البحث المباشر في الويب، تحتاج إلى Cloudflare Worker مع OpenAI API في حساب مستقل، وتكاليف استخدام API. ملف `worker.js` يستورد `topics.json`, `evidence.json`, `doubts.json`, `hadith.json` في الجذر. الخطوات:

1. ثبّت Node.js، وشغّل `npx wrangler login` داخل المجلد الذي يحتوي على جميع الملفات بعد فك ZIP.
2. شغّل `npx wrangler secret put OPENAI_API_KEY`، ولا تنشر المفتاح في GitHub أو في محادثة.
3. شغّل `npx wrangler deploy`؛ تحقق من نجاحه ومن URL الفعلي الذي تحصل عليه.
4. ضع رابط Worker فقط في `config.js` داخل `API_BASE_URL`. لا تضع `/api/ask` داخل القيمة؛ الموقع يضيفها آليًا.
5. أعد رفع `config.js` إلى GitHub وجرب سؤالًا من قاعدة المعرفة وسؤالًا جديدًا؛ تأكد من ظهور الاستشهادات القابلة للفتح.
6. قبل السماح باستخدام واسع، أضف Cloudflare WAF/Rate Limiting وحماية إساءة الاستخدام وحَدًا للإنفاق. `store:false` لا يزيل سياسات سجلات السلامة لدى الخدمات.

## اختبارات
```bash
python validate_content.py
node --check app.js
node --check worker.js
python -m http.server 8000
```
افتح http://localhost:8000/ للتجربة من جهازك، أو انشر GitHub Pages. فتح `index.html` مباشرة عبر `file://` قد يمنع `fetch` لملفات JSON في المتصفح. لعرض نسخة جديدة بعد النشر، أعد تحديث الصفحة تحديثًا قويًا `Ctrl+F5`.

## الخصوصية
بيانات التقدم والمفضلة محفوظة محليًا على الجهاز. عند ربط Worker تُرسل أسئلة الدردشة إلى الطرف الخارجي (Cloudflare وOpenAI). يجب استكمال معلومات المشغّل القانونية ووسيلة تواصل حقيقية قبل إطلاق الخدمة للجمهور. لا تعالج شؤون الزواج أو الطلاق أو الميراث قضائيًا أو طبيًا اعتمادًا على مولّد الأجوبة دون أهل الاختصاص.

**المصدر لا يساوي التصديق على كل اجتهاد؛ التوثيق يحتاج ملاءمة الدليل للحكم وفهم سياقه ومقابلة أقوال المذاهب.**

## الصيانة في V4
- فحص توافق الملفات والمسارات في جذر ZIP مع GitHub Pages، وإظهار شاشة خطأ مفهومة إن نقصت ملفات البيانات.
- تحسين ربط الروابط العميقة للمسائل، وإغلاق النافذة عند الانتقال، وتنقل لوحة المفاتيح.
- إضافة فهرس بحث في الأدلة المباشرة وتصفية نوع المراجع، وإحصاءات ديناميكية في الصفحة الرئيسية.
- ربط الرقية الشرعية بحديث صحيح البخاري 5736، وحقوق الحيوان بحديث صحيح البخاري 2363، بدل الإحالات العامة غير المناسبة.
- إعادة 11 عنوانًا كان مستنده مجرد دليل عام إلى الفهرس غير المكتمل، منعًا من الإيحاء بتحقيق فقهي متخصص لا يوجد.
- توضيح الفرق بين الرابط الاستشهادي ورابط البحث اليدوي في المساعد؛ وتحسين مطابقة أسئلة الشبهات لتجنب إجابات غير مرتبطة.
- تحديث نسخة ملفات JS وCSS لتقليل مشكلات ذاكرة التخزين المؤقت بعد رفع GitHub.

**مهم:** نسخة GitHub المنشورة لا تتغير تلقائيًا بمجرد تحميل ملف ZIP. ارفع الملفات كلها (استبدال) ثم حدّث الصفحة تحديثًا قويًا، وتأكد من وجود `topics.json` و`evidence.json` وجميع ملفات JSON في جذر المستودع.
