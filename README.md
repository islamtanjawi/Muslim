# بصيرة V2 — موسوعة تعليمية في الفقه والسنة ومساعد بالمصادر

الموقع عربي متجاوب يعمل على **GitHub Pages** دون إعداد بناء. جميع ملفات النسخة المنشورة في **جذر ملف ZIP مباشرة**؛ لا يوجد مجلد `data`، ولا مجلد موقع آخر داخل ZIP.

## ما هو موجود بالفعل؟

- **24 بابًا** تعرض كلها في الصفحة الرئيسية + فلاتر الأبواب في الموسوعة.
- **253 عنوان مسألة**، منها **112 شرحًا تمهيديًا** مرتبطًا بـ **83 سجلًا مرجعيًا** (آيات مقتطفة، أحاديث، أقوال فقهاء، وقرارات مجمع فقهي). لا تعني الإحالة وحدها أن الأحكام التفصيلية قد حُققت؛ هذه المواد مسودات تحريرية بانتظار مراجعة عالم مؤهل.
- **141 عنوانًا غير محرر**؛ يظل فهرسًا ولا ينتج الموقع له حكمًا مختلقًا.
- صفحة «الشروح والفتاوى» تحتوي مواد تمهيدية وروابط قرارات جماعية وفتاوى منشورة في جهاتها. الموقع **لا ينشر فتاوى شخصية من تأليفه ولا ينتحل اسم أي دار إفتاء**.
- بحث، مفضلة محلية، روابط مشاركة للمسائل، وضع داكن، شاشة هاتف، ومساعد محلي يعرض الإحالات. حين لا يتوفر نص محلي مناسب تظهر للمستخدم **روابط بحث** إلى مواقع موثوقة بدل رسالة فارغة.
- خادم اختياري لتوليد الإجابات بالذكاء الاصطناعي واستخدام `web_search` في OpenAI Responses على نطاقات خارجية مقيدة ومرفقة بالاستشهادات.

## رفع ملفات ZIP على GitHub

1. افتح ZIP؛ سترى الملفات كلها في الجذر: `index.html`, `styles.css`, `app.js`, `config.js`, `worker.js`, `topics.json`, `categories.json`, `evidence.json`, `favicon.svg`, `privacy.html`, `terms.html`, `README.md`, `wrangler.toml`, `validate_content.py`.
2. ارفع **هذه الملفات مباشرة في جذر** المستودع `Muslim` على GitHub. احذف ملفات النسخة القديمة ومجلد `data` القديم **بعد التأكد من وصول ملفات JSON الجديدة إلى الجذر**؛ لا ترفع ZIP نفسه ولا تنشئ مجلدًا خارجيًا.
3. من Settings → Pages استخدم `main` و`/(root)`، وادخل الرابط `https://islamtanjawi.github.io/Muslim/` بعد نشر التعديلات.
4. قد تحتاج GitHub Pages إلى تحديث الملف المنشور وتجاوز نسخة الذاكرة المؤقتة بتحديث قوي (`Ctrl+F5`).
5. بدون خادم، تعمل الموسوعة والبحث المحلي والمساعد القائم على البيانات وروابط البحث الخارجية فقط؛ **لا يوجد ذكاء اصطناعي متصل بالإنترنت عند هذه المرحلة**.

## تشغيل الذكاء الاصطناعي والبحث الخارجي

خادم البحث ملف `worker.js` ويحتاج نشرًا **منفصلًا** على Cloudflare Workers؛ GitHub Pages وحده لا يمكنه حفظ مفتاح API أو الاتصال الآمن بالنموذج.

1. جهّز Cloudflare Workers وحساب OpenAI API برصيد مخصص (اشتراك ChatGPT Plus لا يشمل API تلقائيًا).
2. على الحاسوب ثبّت Node.js، ثم في مجلد الملفات افتح Terminal وشغّل `npx wrangler login`.
3. ملف `wrangler.toml` مجهز بأصل نطاق موقعك `https://islamtanjawi.github.io` (لا تضع مسار `/Muslim`).
4. شغّل `npx wrangler secret put OPENAI_API_KEY`، والصق مفتاحك في نافذة Cloudflare **ولا تضعه أبدًا في GitHub أو `config.js`**.
5. شغّل `npx wrangler deploy`؛ سيظهر عنوان Worker مثل `https://basira-fiqh-assistant.USER.workers.dev`.
6. عدّل `config.js` من `API_BASE_URL: ''` إلى رابط الـWorker الكامل ثم أعد رفع `config.js`.
7. جرب من الموقع سؤالًا موجودًا في JSON وسؤالًا جديدًا. إن نجح البحث، تظهر روابط المصادر الخارجية. عند غياب مراجع صريحة، يتجنب الخادم الجزم ويحيل إلى جهة إفتاء.

### المصادر الخارجية المسموح بها في محرك البحث

`quran.com`، `sunnah.com`، `dorar.net`، `iifa-aifi.org`، `dar-alifta.org`. هذه قائمة تقنية لمصادر البحث، **وليست شهادة بأن كل صفحة أو رأي فيها محل إجماع**. راجع كفاءة المصادر ومعايير التحرير قبل التوسع. عند تعطّل البحث الخارجي تظهر روابط بحث مقترحة يمكن فتحها يدويًا.

### ضوابط منهج أهل السنة في النسخة

- القرآن الكريم والسنة الثابتة هما مرجعان أساسيان، مع قراءة النصوص في سياقها وجمع بقية الأدلة.
- يذكر نص الحديث وكتابه ورقمه وتخريجه عند توفره؛ يميز النص الأصلي من المقتطف أو الوصف التلخيصي، ولا يجعل الحديث الضعيف حجة دون تفصيل علمي.
- ينسب أقوال العلماء إلى أصحابها، ومنهم ابن القيم، دون خلطها بالنص النبوي.
- تحترم الأقوال السنية المعتبرة لدى الحنفية والمالكية والشافعية والحنابلة، ولا تُقدّم المسائل الخلافية على أنها إجماع.
- **لا يوجد اعتماد من هيئة شرعية أو عالم متخصص للنسخة الحالية**؛ لذلك لا يصح الإعلان أنها توافق السنة في كل حكم على وجه القطع، ولا بناء قرارات الطلاق أو الميراث أو العقود الخاصة عليها وحدها.

## الأمان والجودة

- حد أولي 8 طلبات في الدقيقة لكل IP في ذاكرة Worker المحلية؛ ليس Rate Limiting موزعًا، ويفضّل إضافة Cloudflare WAF/Rate Limiting وTurnstile وحدود إنفاق خدمة API قبل النشر الواسع.
- لا تضع بيانات حساسة في المحادثة؛ استدعاءات الذكاء الاصطناعي تُرسل سؤال المستخدم إلى OpenAI (`store:false` في الطلب)، وراجع سياسة الخصوصية وملء بيانات جهة إدارة الموقع قبل الإطلاق للجمهور.
- الأدلة الحالية مسودات لا يجوز تسويقها باعتبارها فتاوى مؤسسة معتمدة. يلزم مراجعة علمية، وتوثيق درجة الأحاديث، ومنظومة تحرير وتحديث قبل توسعة الأجوبة إلى كل مسائل الفهرس.
- تحقّق من الترخيص قبل استنساخ نصوص طويلة من كتب أو موسوعات. الروابط قد تتغير مستقبلًا.

## اختبارات قبل النشر

```bash
python validate_content.py
node --check app.js
node --check worker.js
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`؛ لا تختبر جلب JSON بفتح ملف HTML على `file://`. نجحت اختبارات HTML/JS داخل بيئة متصفح مع بيانات محاكية لتوصيل JSON على عرضَي 1300px و390px. **لم يتم اختبار تشغيل Worker على حساب Cloudflare أو مفتاح OpenAI حقيقي**؛ هذا يحتاج إعدادك للخدمة.
